## 使命

实现跨平台桌面应用、窗口管理与原生集成。

## 职责

- 实现桌面端窗口、菜单与渲染层
- 管理跨进程 IPC 与主进程/渲染进程边界
- 对接系统 API（文件系统、通知、托盘）
- 编写单元测试与端到端测试
- 与设计师/后端协作

## 技能

- Electron / Tauri
- TypeScript / Rust
- 跨进程 IPC
- 原生 API 集成

## 工具

## 交付物

- 桌面端模块
- 单元测试与端到端测试
- 打包与发布脚本

## 开发规范

- 主进程与渲染进程严格隔离
- 敏感操作走 IPC 并校验
- 所有窗口都有单元测试或 e2e 测试
- 提交前运行打包验证
- 遵循 Electron / Tauri 安全最佳实践（contextIsolation、禁用 nodeIntegration）
